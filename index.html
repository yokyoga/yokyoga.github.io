About

Engineering systems, evaluating intelligence

I am a Software Engineer with a dual background that sits at an increasingly valuable intersection: building production fullstack systems, and evaluating the quality of the AI models that are starting to consume them.

On the engineering side, I have spent over six years shipping web and mobile applications across government, banking, and logistics. My focus is scalable backend architecture and clean REST API design guided by SOLID principles, with hands-on delivery in Python (FastAPI), Go, Node.js, TypeScript, and PHP (Laravel, CodeIgniter) — backed by PostgreSQL, MySQL, and Oracle DB.

On the AI side, I work freelance as an Annotation Analyst evaluating Large Language Model responses across Harmlessness, Honesty, and Helpfulness, performing Static Preference Ranking (SPR) and Interactive Preference Collection (IPC), running Verification Review & Annotation (VRA), and handling Arabic image annotation.

That combination means I can both build the pipeline and judge what flows through it — writing the API that serves a model, and assessing whether the model's output is actually correct, safe, and useful.
